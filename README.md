# Azadi Studio

Real-time Three.js workstation for azadistudio.ir. The room, desk, computer,
keyboard, mouse, headphones, camera, notebooks, pens, glass orb, plants,
armored collectible, vinyl figure and five service icons are mesh geometry.
The previous photograph background and coordinate hotspots have been removed.

- Drag on desktop, or use the orbit buttons on mobile, to move the camera.
- Click service models or objects to open the existing service descriptions.
- Use Enter workstation, Reset view, lighting and animation controls.
- Canvas textures contain procedural material grain and monitor lettering only.
- Three.js 0.180.0 and required addons are vendored; no runtime CDN dependency.
- GitHub Actions deploys the static source directly to GitHub Pages.

Run locally with `python -m http.server 8000` from this directory.
Open http://localhost:8000 in a browser with WebGL 2 enabled.
